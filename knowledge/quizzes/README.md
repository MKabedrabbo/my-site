# Quizzes

Self-check quizzes based on what's actually in the Notion learning plan and
what's actually been built in this repo. One file per quiz — questions up
top, answer key at the bottom under a horizontal rule so you can attempt it
before peeking.

## How this works

1. Take a quiz — answer in your own words (out loud, in chat, or on paper),
   *then* check the answer key at the bottom of that file.
2. Tell Claude how it went (which ones you got, which you missed, where you
   guessed).
3. Claude logs the attempt in `results.md` — what you knew solidly, what
   needed a nudge, what to revisit.

Results are a record for you, not a grade — the point is finding gaps
before an interview does.

## Quizzes available

- `phase-0-fundamentals.md` — DNS, HTTP, REST, JSON, cookies, browser internals
- `phase-1-git-github.md` — Git, GitHub, deployment, CI/CD

## Log

See `results.md` for the full history of attempts.
